# Keybinding reference (from the Sway config)

`Super` = `$mod`. Verified against `home/.config/sway/config`.

## Apps
| Keys | Action |
|---|---|
| Super+Return | foot terminal |
| Super+Space | launcher (`launcher.sh`) |
| Super+Esc / Super+Alt+Space | system menu |
| Super+K | key cheat-sheet |
| Super+Shift+B / F / T | Firefox / Thunar / top in foot |
| Super+Ctrl+V | clipboard history (cliphist + wofi) |
| Super+Ctrl+L | lock |
| Super+Shift+C | reload Sway |
| Super+, / Super+Shift+, | dismiss one / all notifications |

## Windows and layout
| Keys | Action |
|---|---|
| Super+W | close |
| Super+F | fullscreen |
| Super+Shift+Space | toggle floating |
| Super+J | toggle split direction |
| Super+G | toggle tabbed/split |
| Super+Arrows / +Shift | focus / move |
| Super+- , = (+Shift) | shrink/grow width (height) by 100px |

## Workspaces
Super+1..0 go, Super+Shift+1..0 send. Tab / Shift+Tab / Ctrl+Tab for
next / previous / back-and-forth; Super+scroll cycles.

## Hardware keys
Volume, mic mute, and brightness keys work on the lock screen (`--locked`).
Print: region to clipboard; Shift+Print: full screen to file; Super+Print:
region to file (`~/Pictures/Screenshots`).
